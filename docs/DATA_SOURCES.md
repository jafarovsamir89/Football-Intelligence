# Data sources review

**Reviewed:** 2026-11-09. Policies, quotas, endpoints, leagues, and terms can change; verify the provider's live documentation before enabling any new integration. “Free to access” does not automatically mean permission to republish or automate access.

## Decision

The app currently uses OpenLigaDB for selected fixtures/results and user-entered odds/picks. The next authorized data step is a transparent manual CSV/JSON import that preserves origin, market type, observation time, and terms. There is no free source confirmed for reliable, broad, current bookmaker odds plus licensed tipster history with no key/account restrictions. We will not scrape private or restricted services to fill that gap.
