# Football Intelligence — дорожная карта Android

## Цель

Личное Android-приложение без платы за источники: автоматически получает разрешённые футбольные расписания и результаты, хранит их локально, строит честные вероятности и сверяет виртуальные прогнозы. Для The Odds API пользователь создал бесплатный аккаунт и дал ключ личной локальной сборке; в самом приложении нет входа, букмекерских аккаунтов, реальных ставок или платных API.

## Далее

- Продолжать накапливать неизменяемые предматчевые прогнозы и оценивать их по будущим результатам; доступ к более поздней сохранённой локальной базе сейчас не подтверждён.
- P2 Poisson baseline, paired Elo/Poisson holdout и validation-only подбор Dixon–Coles rho записаны в аналитическом отчёте; rho не меняет live Elo. Продолжить собирать проспективные прогнозы и результаты для независимой оценки.
- P3: строить value-исследование только после независимой будущей проверки и лишь при одновременно свежем полном local-book price, точном fixture link и достаточно проверенной модели. На текущих данных никаких EV сигналов нет.
- P4 coupon settlement, coverage reporting, separate Probability/Market-Disagreement cohorts, and Fréchet bounds are implemented. Continue to gather prospective outcomes per model version and show no single joint probability unless a dependence model is validated.
- Проверить обновление MoviOdds непосредственно на физическом телефоне в Азербайджане, когда телефон будет подключён к ADB; до этого региональную доступность не заявлять. Продолжить искать другие источники только с явным разрешением; не автоматизировать страницы с запрещённым scraping и не смешивать разные букмекеры.
- Продолжать собирать будущие exact-linked котировки и результаты; консенсус доступен только после поступления линий от нескольких разных underlying bookmakers. TipsAudit остаётся производной fair-reference, не named-bookmaker quote.
- Room/DAO сейчас отложен: доказанная проблема главного потока уже решена repository + IO, а отдельной потребности Room пока нет. Перед будущим переходом определить формат резервной копии и доказать сохранение всех таблиц/ID и rollback на копии базы v16 на API 26/34.
- Добавлять рынки только с независимой схемой рынка, точной стороной, source URL и timestamp.
- Показывать conditional EV диапазон только по полной свежей линии одного оператора и явно называть его экспериментальным; не выдавать его за прибыль и не смешивать котировки в купоне.
