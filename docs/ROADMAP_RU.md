# Football Intelligence — дорожная карта Android

## Цель

Личное Android-приложение без платы за источники: автоматически получает разрешённые футбольные расписания и результаты, хранит их локально, строит честные вероятности и сверяет виртуальные прогнозы. Для The Odds API пользователь создал бесплатный аккаунт и дал ключ личной локальной сборке; в самом приложении нет входа, букмекерских аккаунтов, реальных ставок или платных API.

## Что реализовано в активной ревизии

- **Распределённое обновление международных линий в пределах бесплатной квоты:** одна выбранная лига за WorkManager-проход раз в два часа, максимум 12 попыток за любое скользящее 24-часовое окно, сохранение остатка квоты и пауза при ≤20 кредитах до окончания первого UTC-дня после месячного сброса, плюс серверный `Retry-After`. Вызовы распределены по суткам, чтобы свежие 15-минутные capture-окна не возникали одновременно. При миграции старой версии с неизвестным количеством запросов в суточном batch новый gate дожидается истечения старого 24-часового окна. Повторное расписание обновляется с помощью WorkManager `UPDATE`; Android может задержать работу. Локальный цикл прошёл 160 JVM-тестов, компиляцию Android-тестов и сборки debug/personal APK; API 26/34 и Actions ожидаются.
