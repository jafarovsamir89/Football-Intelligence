# Azerbaijan-first: Misli and TOPAZ odds without paid APIs

**Reviewed:** 2026-11-13. Previously collected prices are time-stamped observations; snapshots older than 30 minutes are not current.

## User mandate (2026-11-09)
Personal Android APK for Azerbaijan. Automatically retrieve public prematch odds from Misli.az and TOPAZ/eTopaz for private analysis, without manual CSV files, manual coefficient entry, API registration, paid API or server. An official API is not a requirement. Use standard public website rendering and openly accessible data only where allowed. Describe availability only from timestamped captures verified on the current device/session; it may change and a technical capture does not establish reuse permission.

## Research
- Misli official: https://www.misli.az/ . A standard Android API 34 WebView rendered the public football page, including future dates, local kickoff times, team labels and the complete 1/X/2 market. The app's parser reads only `document.body.innerText` from that public page; no private endpoint or account is used.
- Misli [robots.txt](https://www.misli.az/robots.txt), rechecked 2026-11-13, says `Allow: /` while disallowing account, membership, site-settings, shared-coupon, and live-detail path patterns. This is a crawler directive; it does not establish a license or affirmative right to automate reuse of odds. No explicit public reuse permission was found.
- TOPAZ official: https://etopaz.az/ and https://topaz.az/ . The ordinary public home page has an `İdman` tab. Selecting that visible tab in a standard Android WebView showed future 1X2 football events; the app performs the same normal tab click and reads visible page text. The current [official English terms](https://www.etopaz.az/eng/terms-conditions), rechecked 2026-11-13, are a BAL LINE subscriber contract. Clauses 8.7–8.8 reserve rights to site materials and say subscribers need written permission to use/copy/publish them. The contract does not expressly resolve anonymous public-page collection by a non-subscriber; this is not treated as permission or a definitive prohibition for that case. Do not infer permission from subscriber-account restrictions.
- Existing open source reference: [aliabbasov99/ai-football-prediction](https://github.com/aliabbasov99/ai-football-prediction), [backend/scripts/scrape_misli_all.py](https://github.com/aliabbasov99/ai-football-prediction/blob/main/backend/scripts/scrape_misli_all.py). Its implementation uses `undetected_chromedriver`, stealth flags, scrolling, BeautifulSoup selectors, aliases and fuzzy `SequenceMatcher` similarity. No code or evasion mechanism was copied. This app uses visible standard-WebView text and exact reviewed aliases.

- Misli's live [robots.txt](https://www.misli.az/robots.txt) still allows `/` and lists exclusions for account, membership, site-settings, shared-coupon, and live-detail paths. Robots permission concerns crawler routing only; it is not an odds-reuse license.

Because this is a subscriber agreement, it does not clearly settle collection from an anonymous public page; the app records no affirmative permission and must not broaden the collector based on that ambiguity.
- On the disposable API 34 first-run on 2026-11-13, ordinary visible-page capture found no verifiable future prematch 1X2 rows for Misli or eTopaz and recorded `UNAVAILABLE`. This is a single time-bound observation, not evidence of a block, regional restriction, or permanent outage. No challenge, login, hidden endpoint, or control bypass was attempted.
- Existing historical snapshots remain local and freshness-gated. Keep this source status distinct from international feeds; those do not supply Misli/TOPAZ quotes. If a standard public page does not yield verifiable rows, show unavailable and continue using cached football history/results.

## Separate international fair-market reference

TipsAudit's no-key attributed API is a separate market-reference source. It does not provide raw Misli or TOPAZ quotes and cannot fill a missing local price. It is stored in its own SQLite v12 ledger, filtered to source reads no older than 30 minutes and strictly before kickoff, and compared only after a unique exact fixture join. Its derived probabilities are descriptive; its price/value fields are excluded from local bookmaker coupons and EV. On the 2026-11-11 POC, the Türkiye—Belgium fair read was about 47 minutes old and was therefore rejected. Direct Pinnacle, Betfair Exchange and bet365 feeds remain unavailable/blocked under the free, no-account, permitted-access requirement; details are recorded in [DATA_SOURCES.md](DATA_SOURCES.md).

### One permitted international bookmaker feed

MoviOdds publishes a documented no-key public JSON feed of bet365 odds and its current terms permit use in one's own app, require users to be at least 18, and prohibit bypassing rate/security controls. The app labels the data **bet365 via MoviOdds** because MoviOdds is an independent intermediary, not bet365; this does not establish a bet365 reuse license or endorsement. The user confirmed 18+; that provider-specific setting does not gate other sources or football sync.

The Odds API V4 is now a second, independent international source, with real bookmaker identities and a personal free key supplied by the user. Its standard `h2h` response includes `h2h_lay` for exchanges; the adapter requests available outcome bet limits and stores Back and Lay separately. Lay does not enter back-price consensus or prospective Elo comparison. The UI compares Back/Lay only from the same captured response. Commission is not supplied or subtracted, and source bet limits are not treated as liquidity. Its official terms allow mobile app display/storage but require private key handling; the key is in ignored local configuration and only the local personal build embeds it. The keyless CI APK does not contain it. A bounded 12-request/24-hour schedule observes the account quota, and accepted prices expire from fresh use after 15 minutes. Its POC and exact matching limits are documented in [DATA_SOURCES.md](DATA_SOURCES.md). Neither international source populates Misli/TOPAZ virtual coupons. No physical-phone access from Azerbaijan has been verified.

The browser checks did not use login, place bets, access account/detail paths, solve a challenge, or bypass controls. Misli's public route is allowed by its robots file, but that file is not a license; eTopaz's robots file was not retrievable. The eTopaz terms govern subscriber wagering/account use but do not expressly authorize anonymous odds reuse. Explicit automated odds-reuse permission was not found for either operator. The app keeps captures local and does not redistribute them. `LIVE` means a recent foreground technical capture contained future visible lines; it is not legal authorization, a guarantee that prices remain open, or a claim that a model is profitable. Android may defer or stop page rendering. The old API 34 build did fail to save a capture during result sync, but commit `01706e9` passed Actions and the updated APK captured both providers without another `database is locked` error. An isolated API 34 emulator had no active network and returned WebView's internal `chromewebdata` page; that is an offline harness condition, not a bookmaker restriction. No hidden endpoint or evasion fallback is used.

## Implementation and open requirements

- Both independent provider adapters are implemented and use only the ordinary public WebView and visible page text; no hidden API, login, stealth, CAPTCHA solving or protection bypass is used.
- Both parsers require a future event, local date/time and device timezone, a complete labeled 1/X/2 sequence, prices in range and a public route. Misli has an explicit date; eTopaz's year is inferred only within 90 days and explicitly flagged. Live-score, incomplete/suspicious prices, past events and conflicting duplicates are rejected. Team matching uses reviewed exact aliases and preserves home/away orientation; fuzzy matching is not used.
- Each snapshot stores provider, source URL, UTC capture time, local date/timezone, raw labels, market/prices and optional unique exact local match ID. Unmatched quotes are not compared with Elo.
- Freshness is 30 minutes, checked both when loading rows from SQLite and inside the coupon builder; future-dated captures are rejected. Each provider's accumulator uses only its own complete, exact fresh lines. If none exist, model probabilities remain available with no price/payoff.
- Still open: no explicit automated reuse permission was found in the operator terms. Check any new terms before enabling broader automated use, and do not redistribute quotes. Verify timezones/devices beyond API 34. If either source restricts access, keep it unavailable and do not evade restrictions.

## Statistical honesty
Model win probability and actual available bookmaker decimal odds are different objects. Estimate EV only when source-specific quote exists and model is reasonably calibrated. Otherwise show probabilities and a missing market price, not an invented payoff or betting recommendation.

## Product behavior
Zero actions required by user on first launch beyond granting network access; result sync is best effort under WorkManager restrictions. Both bookmaker WebViews load automatically on app open and retry every 30 minutes while foreground; WorkManager does not run an offscreen browser. Local quotes/results remain stored offline, but quotes older than 30 minutes are not presented as fresh. Manual entry can remain under advanced settings only. No login, no account or payment actions.
