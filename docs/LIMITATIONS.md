# Current limitations

The app is an offline-first research notebook with experimental probabilities, not a validated betting product.

- OpenFootball and OpenLigaDB sync are implemented with local persistence, provider timestamps, retry/backoff, cache and duplicate suppression. A clean API 34 install stored 39,330 merged match records (30,180 with completed scores) across 188 competitions and five seasons. Coverage and update timing still depend on upstream availability/completeness. API 26 and physical-device runs remain outstanding.
- OpenLigaDB is community-maintained. The app discovers football competitions for five calendar-year catalogs, but an 8-minute per-worker budget may spread first-run history acquisition across retries. WorkManager is best-effort and Android may defer work.
- OpenFootball rows without exact kickoff time are shown as date-only; they cannot generate a kickoff-based forecast or be treated as exact. Historical results are held until the conservative availability date.
- Cross-feed deduplication is intentionally strict: same event date, normalized team names, and same home/away order. If names do not normalize exactly or multiple same-day candidate fixtures exist, both records remain rather than guessing.
- Misli's standard WebView collector captured eight public prematch 1X2 rows on API 34, including five rows cross-checked against UEFA's published 10 Nov 2026 Women's Champions League schedule. The rows did not map to an exact local fixture, so the app does not show model comparisons for them. The public `robots.txt` allows the route, but no affirmative odds-reuse license was located; snapshots stay on-device and are not redistributed. This is technical verification, not legal clearance or a guarantee quotes remain open. WebView capture runs on app open/foreground, not through WorkManager; older than 30-minute lines are hidden.
- TOPAZ's normal public page exposed 25 future 1X2 rows on API 34 after the visible `İdman` tab was selected. Türkiye–Belgium's time and event were cross-checked against UEFA's Nations League schedule. eTopaz omits the year, which the parser infers as the next occurrence within 90 days and flags in stored data. None of the 25 rows matched an exact local fixture. Explicit automated reuse terms were not established; snapshots stay local. No live market is accepted and no odds are fabricated.
- The automatic source walk-forward evaluated 29,970 historical targets and produced 19,078 forecasts (Brier 0.6105; Log Loss 1.0234 on this API 34 database). It uses competition-specific time cutoffs and excludes results whose saved availability is not earlier than the target. The current files are not historical source vintages, so these retrospective scores are experimental and cannot establish future calibration or an edge. Forty prospective model picks were stored on this device; none had settled at inspection time.
- The automatic coupon drafts select the highest Elo probability for each eligible fixture and store a pre-match pick for later result checking. This is not a value filter or a validated recommendation; no probability calibration, independent future test, stake sizing, joint coupon probability, or correlation model exists.
- Elo uses fixed transparent defaults and requires at least 10 prior same-league matches and 3 appearances per team. The estimate is uncalibrated. Poisson/Dixon–Coles are math primitives only; no expected-goals features are connected.
- CSV walk-forward remains optional in Settings → Additional. The app also runs a walk-forward over automatic-source results; its source-availability assumptions and lack of archived versions limit historical interpretation.
- The app does not import crowd/tipster picks. No free permitted automated tipster feed was confirmed.
- The previous manual quote/ticket database is preserved for upgrades, but manual quote entry is not part of the current main user flow. No real bet or bookmaker account action exists.
- GitHub Actions builds a debug APK signed with the debug key. Release signing and Play Store distribution are not configured.
