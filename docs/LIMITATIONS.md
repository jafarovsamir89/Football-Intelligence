# Current limitations

The app is an offline-first research notebook with experimental probabilities, not a validated betting product.

- OpenFootball and OpenLigaDB sync are implemented with local persistence, provider timestamps, retry/backoff, cache and duplicate suppression. The final API 34 sync stored 39,181 merged rows across 184 competitions; both providers reached `OK` through bounded WorkManager retries. The API 26 Android 8 CI-artifact update-install opened without a fatal exception. Without further APK updates, its latest readable state at 2026-11-10 03:29 UTC reached 29,490 rows, OpenFootball `OK`/25,904, OpenLigaDB `PARTIAL`/5,463 and 57 league states; the worker released its lock and is awaiting continuation. Full API 26 sync remains unverified. Emulator connectivity itself was validated. The physical device and a completed API 26 sync remain unverified.
- OpenLigaDB is community-maintained. The app discovers football competitions for five calendar-year catalogs, but an 8-minute per-worker budget may spread first-run history acquisition across retries. WorkManager is best-effort and Android may defer work.
- OpenFootball rows without exact kickoff time are shown as date-only; they cannot generate a kickoff-based forecast or be treated as exact. Historical results are held until the conservative availability date.
- Cross-feed deduplication is intentionally strict: same event date, normalized team names, and same home/away order. If names do not normalize exactly or multiple same-day candidate fixtures exist, both records remain rather than guessing.
- On the latest API 34 foreground pass at 2026-11-10 03:07 UTC, Misli returned 9 public future 1X2 lines (0 exact local forecast links) and TOPAZ returned 25 (7 exact local fixture links). Portugal—Denmark / match 85257 again showed 1.45/4.31/5.29; this snapshot is time-bound and expires after 30 minutes. Earlier model comparison for that fixture was 59.1% Elo home marginal and 62.1% basic no-margin home probability. These captures verify one emulator/timezone, not ongoing availability or legal permission. On API 26's old emulator WebView, both public pages returned no visible text and were recorded `ERROR`; no hidden endpoint or evasion fallback is used. Explicit automated odds-reuse permission remains unconfirmed; captures stay on-device. WebView capture runs in foreground, not through WorkManager.
- The app now builds independent same-bookmaker price-backed virtual accumulators when every leg has a fresh exact fixture match. Current capture produced TOPAZ 2/3/5-leg drafts (combined captured prices 1.75/2.09/26.87); Misli had too few mapped quotes. These are immutable pre-match observations and not live guarantees. Model-only drafts remain available without prices. Marginal probabilities are combined only into Fréchet lower/upper bounds; no independence model or real payout claim exists. No coupon has settled yet, so historical ROI and hit rates are unavailable.
- The local DB includes 566 legacy placeholder-team rows. They are retained for migration safety but hidden from normal results and excluded from forecasts, picks, fixture linking, accumulators and walk-forward; parser/upsert paths reject new placeholders. Post-filter automatic-source walk-forward: 29,588 targets, 19,185 forecasts, 10,403 insufficient-history skips, Brier 0.6106, Log Loss 1.0235. This is still retrospective and uncalibrated.
- Automatic coupon drafts select the top available Elo marginal per eligible fixture. This is not a value filter or validated recommendation. No probability calibration, independent forward test, stake sizing, or dependence/correlation model exists. Accumulator outcomes are checked against saved local results; a kickoff move above 30 minutes is marked for review instead of treated as a loss.
- Elo uses fixed transparent defaults and requires at least 10 prior same-league matches and 3 appearances per team. The estimate is uncalibrated. Poisson/Dixon–Coles are math primitives only; no expected-goals features are connected.
- CSV walk-forward remains optional in Settings → Additional. The app also runs a walk-forward over automatic-source results; its source-availability assumptions and lack of archived versions limit historical interpretation.
- The app does not import crowd/tipster picks. No free permitted automated tipster feed was confirmed.
- The previous manual quote/ticket database is preserved for upgrades, but manual quote entry is not part of the current main user flow. No real bet or bookmaker account action exists.
- GitHub Actions builds a debug APK signed with the debug key. Release signing and Play Store distribution are not configured.
