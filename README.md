# Football Intelligence — Android Lab

**Личная Android-лаборатория футбольных данных и виртуальных ставок.** Без платных подписок, сервера и обязательного API-ключа.

## Правила

- Нативное Android-приложение на Kotlin + Jetpack Compose с локальной SQLite. Без сервера и регистрации.
- Расписание и результаты автоматически загружаются из [OpenLigaDB](https://api.openligadb.de/index.html) и лицензированных наборов [OpenFootball football.json](https://github.com/openfootball/football.json). Ключ не нужен; локальная база остаётся доступной офлайн.
- OpenLigaDB обнаруживает доступные футбольные лиги по API, проверяет изменения и ограничивает частоту запросов. OpenFootball проверяет каталоги пяти сезонов и сохраняет фактическое время загрузки; даты без точного времени не используются как точный kickoff.
- WorkManager запускает синхронизацию при первом открытии и повторно при устаревшей базе, затем ежедневно в best-effort режиме. Android может отложить фоновые задачи.
- Misli и TOPAZ/eTopaz читаются из видимых публичных страниц стандартным Android WebView при открытом приложении. Последний API 34 проход получил 10 линий Misli и 25 TOPAZ; 7 котировок TOPAZ точно сопоставлены с локальными матчами. Проверены отдельные TOPAZ виртуальные экспрессы (2/3/5 исходов) с сохранёнными котировками. Снимок старше 30 минут не используется. WebView не запускается WorkManager; условия автоматического повторного использования операторских цен не подтверждены, снимки остаются на устройстве.
- Данные, записи котировок и виртуальные ставки хранятся только на устройстве. Нет реальных ставок и подключения к букмекерским аккаунтам.
- Метрики исследовательские. Расхождение между линиями не является доказательством положительного EV.

## Реализовано

1. Автоматический сбор матчей, дат и результатов из нескольких сезонов и доступных соревнований OpenFootball и OpenLigaDB с локальным кэшем, ETag/Last-Modified, лимитом OpenLigaDB, backoff и сохранением provenance.
2. Главный экран показывает свежесть, последний успех, статус источников, список матчей и отдельную историю завершённых результатов.
3. Экспериментальный Elo 1X2 строится локально по истории той же лиги с проверкой cutoff и минимального размера выборки.
4. Раздельные виртуальные купоны Misli и TOPAZ строятся только по своему провайдеру. Конструктор проверяет свежесть и точное сопоставление каждой линии, показывает общий коэффициент только при полной линии на всех исходах и сохраняет время снимка. Если линий недостаточно, остаётся модельный подбор с маргинальными вероятностями и границами Фреше; совместное произведение вероятностей не предполагается.
5. CSV-импорт остаётся дополнительной функцией в настройках; он не нужен для обычного первого запуска.
6. Тестируются парсеры OpenFootball/OpenLigaDB, строгая дедупликация событий, статусы недоступных букмекеров и построение купона без вымышленных цен.

На API 34 база содержит 39 181 объединённую строку из 184 соревнований (OpenFootball 25 904, OpenLigaDB 17 776). При проверке обнаружено 566 старых строк с фиктивными именами команд: они оставлены в SQLite для безопасной миграции, но скрыты от списка, моделей, купонов и оценки; новые такие строки отклоняются. После фильтрации walk-forward: 29 588 целей, 19 185 прогнозов, Brier 0.6106, Log Loss 1.0235. Это ретроспективная оценка текущих файлов, а не архивных версий источников; она не доказывает будущую точность или доход. Офлайн-перезапуск ранее сохранил расписание и статусы источников.

Последний API 34 WebView POC получил 10 линий Misli (точных локальных связей 0) и 25 TOPAZ; последняя выборка связала 7 котировок с точными локальными матчами по проверенным псевдонимам, ориентации команд и времени kickoff. Например, Portugal—Denmark сопоставлен с OpenLigaDB ID 85257: TOPAZ H 1.45, расчёт Elo H 59.1%, базовая нормированная рыночная вероятность H 62.1%. Это снимок на время захвата, не обещание текущей цены или дохода. Условия автоматического повторного использования не подтверждены; снимки остаются локальными. WorkManager может быть отложен Android.

## Android APK

Последняя успешная CI-сборка: [GitHub Actions 42749894995](https://github.com/jafarovsamir89/Football-Intelligence/actions/runs/42749894995) для diary-only коммита `0fac233` (75 тестов, APK, стабильная подпись); код APK — из проверенного коммита `c7bf03c`, [run 42749108983](https://github.com/jafarovsamir89/Football-Intelligence/actions/runs/42749108983). Артефакт `c7bf03c` проверен по сертификату и обновил API 34 установку без удаления; SQLite v10 и 39 181 матч сохранены. APK — тестовая debug-сборка, не релиз Play Store. CI APK подписываются стабильным приватным тестовым ключом для установки поверх сохранённых данных.

Локальный build/tests и CI для `c7bf03c` прошли (75 тестов). API 34 CI-установка сохранила 39 181 матч, 163 снимка котировок и 59 виртуальных купонов; свежий capture получил 9 Misli и 25 TOPAZ линий (7 точных связей). На API 26 синхронизация продолжается через WorkManager: на 2026-11-10 03:29 UTC последняя БД показывала OpenFootball `OK`/25 904, OpenLigaDB `PARTIAL`/5 463, 57 обработанных лиг и всего 29 490 строк; задача ожидает следующего повтора. Полный импорт ещё не подтверждён. Старый WebView не получил видимый текст Misli/TOPAZ.
