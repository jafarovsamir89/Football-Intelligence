# Football Intelligence — Android Lab

**Личный Android-анализатор футбольных рынков без платных подписок и обязательных API-ключей.**

## Правила
- Android APK, Kotlin + Jetpack Compose, локальная SQLite. Без сервера и авторизации.
- Бесплатное расписание и результаты: [OpenLigaDB](https://api.openligadb.de/index.html), без регистрации, только поддерживаемые лиги. Соблюдать лимит 60 запросов в минуту; приложение запрашивает данные только по действию пользователя.
- Коэффициенты **не обещаются автоматически**: пользователь вводит котировки 1X2 по 3 исходам для каждого букмекера. В будущем добавляется *опциональный* официальный бесплатный API; без ключа приложение полноценно работает в ручном режиме.
- Прогнозы/пики игроков добавляются вручную с именем источника. Не считать их подтверждёнными ставками; отдельные копии одного происхождения не должны засчитываться как независимые.
- Данные, цены, виртуальные ставки и результаты сохраняются **только на устройстве**. Никаких реальных ставок и автоматизации букмекерских аккаунтов.
- Все метрики — исследовательские. Разница с рыночной линией не является доказательством положительного EV.

## Функциональность первого этапа
1. Загрузка календаря Бундеслиги / второй Бундеслиги с OpenLigaDB.
2. Отображение предстоящих и завершённых матчей, сохранение локально.
3. Ручной ввод линий 1X2 у нескольких букмекеров с отметкой времени.
4. Добавление прогнозов разных авторов для конкретного исхода.
5. Сравнение букмекерских коэффициентов и вероятностей после удаления маржи, проверка свежести.
6. Виртуальные одиночные ставки: фиксируется цена до начала матча, после результата рассчитываются выигрыши/проигрыши и ROI.
7. Адаптивный интерфейс, история, полное отсутствие платежей.

## Android APK
В GitHub: **Actions → Build Android Debug APK → Run workflow**. После успешной сборки скачай artifact `football-intelligence-debug-apk` и установи `app-debug.apk` на Android. GitHub Actions может требовать активации для репозитория; сборка проходит на GitHub-hosted runner. APK пока не подписан релизным ключом — это тестовая сборка, подписанная debug-ключом.

Локально: Android Studio + JDK 17; импортируй корень репозитория как Gradle-проект. `gradle assembleDebug` с Gradle 8.11.1 (или выполни `gradle wrapper --gradle-version 8.11.1`).

## Дальнейшее развитие
- Импорт исторических CSV при подтверждённых правах использования.
- Экспрессы 2/3/5/10 событий с контролем корреляций и котировок одного оператора.
- Временные снимки линий, CLV, хронологические тесты и калибровка.
- Локальный аналитический движок (Dixon–Coles/Poisson в отдельном модуле) после накопления проверяемых данных.
- Без обхода авторизации, закрытых API, массового scraping и незаконных источников.

## Прозрачность
Ни один купон, процент прохода или ROI не гарантирует доходность. На экране должно быть явно видно: данные букмекера, время измерения, источник прогноза, подтверждённость матча и статус виртуальной ставки. Не использовать выдуманные котировки в реальных расчётах.
