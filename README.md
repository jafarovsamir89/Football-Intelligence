# Football Intelligence — Android Lab

**Личная Android-лаборатория футбольных данных и виртуальных ставок.** Без платных подписок и backend-сервера. База матчей работает без ключа; отдельный источник The Odds API использует личный бесплатный ключ только в закрытой локальной APK-сборке.

## Правила

- Нативное Android-приложение на Kotlin + Jetpack Compose с локальной SQLite, без собственного backend-сервера и входа в приложение. Для The Odds API используется внешний личный бесплатный ключ только в owner-only сборке.
- Расписание и результаты автоматически загружаются из [OpenLigaDB](https://api.openligadb.de/index.html) и лицензированных наборов [OpenFootball football.json](https://github.com/openfootball/football.json). Ключ не нужен; локальная база остаётся доступной офлайн.
- OpenLigaDB обнаруживает доступные футбольные лиги по API, проверяет изменения и ограничивает частоту запросов. OpenFootball проверяет каталоги пяти сезонов и сохраняет фактическое время загрузки; даты без точного времени не используются как точный kickoff.
- WorkManager запускает синхронизацию при первом открытии и повторно при устаревшей базе, затем ежедневно в best-effort режиме. Android может отложить фоновые задачи.
- Misli и TOPAZ/eTopaz читаются из видимых публичных страниц стандартным Android WebView при открытом приложении. Capture 21:04–21:05 UTC ранее получил 9 линий Misli и 25 TOPAZ (точные локальные связи — 0/9 и 7/25), но эти котировки истекли. Автоматическая проверка в 21:34:53 и 21:35:11 UTC не нашла на публичных страницах проверяемых будущих линий и установила `UNAVAILABLE`; новых цен не сохранено. Повторные WebView callback-и теперь коалесцируются в один capture на 30-минутное окно, и страница загружается при истечении свежести, пока приложение остаётся открытым. WAL устранил ранее воспроизведённую блокировку SQLite. WebView не запускается WorkManager; явные права повторного использования операторских котировок не подтверждены. Снимки хранятся на устройстве.
- Добавлен отдельный TipsAudit provider для производной fair-market оценки 1X2. Он не подменяет цены Misli/TOPAZ, не участвует в купонах/EV и не называется Pinnacle/Betfair/bet365. WorkManager проверяет источник при открытии, если прошлой проверки нет или прошло 15 минут, и далее best-effort каждые 30 минут. Сохраняются только события `fair_source=live`, предматчевое время чтения не старше 30 минут, валидные взаимно согласованные вероятности/цены и источник-URL; fixture link требует точные алиасы, порядок команд, дату и kickoff в пределах 20 минут. На прямом POC 2026-11-11 API вернул 98 событий, но пример Türkiye—Belgium имел `fair_read_at` на 47 минут старше capture и будет отброшен; свежая линия для сравнения на том capture не была подтверждена. На экране данные сопровождаются видимой ссылкой TipsAudit. Котировки `best_soft_odds` и сигналы value не импортируются.
- MoviOdds предоставляет котировки bet365 через независимый документированный JSON endpoint, это не прямая интеграция или одобрение bet365. Условия требуют 18+; пользователь подтвердил возраст, а разрешение остаётся специфичным для этого источника. Приложение проверяет source poll, время изменения каждой цены, полный рынок, остановку матча, дубли и точное сопоставление. Последний разбор сохраняет quality counts, 30-дневный журнал — статусы проверок; они не являются процентом надёжности. История цен сохраняет только изменения. MoviOdds сам по себе — ориентир одного букмекера; The Odds API отдельно может дать линии других именованных БК. Международные цены не входят в виртуальные купоны Misli/TOPAZ. Исторический MoviOdds POC 2026-11-12 00:39 UTC прошёл quality gate для 904 из 923 событий; работа на физическом телефоне в Азербайджане не подтверждена.
- The Odds API V4 подключён отдельным provider для EU prematch 1X2. Личный бесплатный ключ лежит только в игнорируемом `local.properties` и включается в вариант `personal`; этот APK содержит извлекаемый ключ и не должен публиковаться или отправляться в CI. Обычная CI/debug APK ключа не содержит. До 12 активных лиг запрашиваются за один суточный проход с вращением каталога; линии старше 15 минут не считаются свежими, поэтому бесплатная квота не обеспечивает постоянную свежесть всех лиг. Исторический POC 2026-11-12: каталог из 45 лиг, EPL 20 событий/298 свежих полных линий, расход 1 из 500 кредитов. Это доказательство доступа и формата только на тот момент, не текущие котировки и не проверка связи из Азербайджана.
- Среди рассмотренных альтернатив The Odds Gap запрещает репакетировать свою ленту в приложение; Football-Data.co.uk допускает лишь ограниченную автоматику, а проверенный файл не содержал предстоящих цен; 1.ML требует письменного разрешения на автоматический доступ и архив. The Odds API и MoviOdds остаются двумя интегрированными международными источниками. Консенсус строится только из нескольких свежих линий разных букмекеров на одном точном матче; он не доказывает преимущество.
- Данные, записи котировок и виртуальные ставки хранятся только на устройстве. Нет реальных ставок и подключения к букмекерским аккаунтам.
- Метрики исследовательские. Расхождение между линиями не является доказательством положительного EV.

## Реализовано

1. Автоматический сбор матчей, дат и результатов из нескольких сезонов и доступных соревнований OpenFootball и OpenLigaDB с локальным кэшем, ETag/Last-Modified, лимитом OpenLigaDB, последовательным продолжением длинного импорта и backoff для сетевых ошибок.
2. Главный экран показывает свежесть, последний успех, статус источников, список матчей и отдельную историю завершённых результатов.
3. Экспериментальный Elo 1X2 строится локально по истории той же лиги с проверкой cutoff и минимального размера выборки.
4. Раздельные виртуальные купоны Misli и TOPAZ строятся только по своему провайдеру. Кроме подбора по вероятности модели, доступен отдельный исследовательский подбор по положительному расхождению с полной свежей линией того же букмекера после удаления маржи. Он требует точной связи с локальным матчем; сохраняет рыночную вероятность, разницу и время цены; для него EV/ROI не показываются. В остальных ценовых купонах общий коэффициент есть только при полной линии на всех исходах. Для совместной вероятности используется диапазон Фреше без допущения независимости. Купон сразу считается проигранным после первой неверной завершённой ноги; процент покрытия ценами показывается отдельно.
5. CSV-импорт остаётся дополнительной функцией в настройках; он не нужен для обычного первого запуска.
6. SQLite v17 хранит TipsAudit fair-market snapshots, линии MoviOdds и The Odds API, а также воспроизводимые значения сравнения модели с местной линией в отдельных регистрах/полях. В международном регистре разделены текущие котировки и история, provider/book identity, source poll и capture timestamps, 30-дневные статусы и quality counts. Связь с локальным матчем требует точного kickoff либо единственного совпадения команд и UTC-даты; точность связи сохраняется и показывается. Неоднозначные совпадения отклоняются. Misli/TOPAZ и международные источники остаются изолированными.
7. Walk-forward показывает Brier, Log Loss и one-vs-rest reliability bins для П1/X/П2: ECE, среднюю вероятность, наблюдаемую частоту и размер выборки. Это ретроспективная диагностика, не калибровка модели.
8. Будущие прогнозы модели фиксируются в SQLite неизменяемыми снимками на матч, версию Elo и UTC-день. Отчёт читает весь локальный журнал и для метрик выбирает последний прогноз до kickoff по одному разу на матч/версию модели; проверяет счёт, исход, источник и время доступности результата. Виден список последних 100 записей. До накопления завершённых, проверяемых матчей метрики остаются пустыми.
9. Мировой рынок показывает парную проверку Elo и последней сохранённой свежей международной линии до kickoff по тому же матчу. Букмекеры считаются отдельно; цена оценивается после доступности результата, а отчёт явно показывает объём пар и pending исходы. Это локальный описательный отчёт, не CLV или ROI.
10. Экран анализа сравнивает 27 заранее заданных комбинаций K-фактора, домашнего преимущества и prior ничьих. Параметры выбираются только на следующем хронологическом validation-отрезке по Log Loss; отдельный последний holdout сравнивает выбранные настройки с текущими. При менее чем 100 рассчитанных validation-прогнозах выбор не делается. Это исследовательский расчёт на текущих файлах, не меняющий замороженные или рабочие прогнозы.
11. Журнал экспрессов показывает покрытие полностью сохранёнными ценами. ROI, profit factor и drawdown рассчитываются только если цена есть у каждого завершённого купона в соответствующей группе.
12. В ретроспективном анализе доступен исследовательский Poisson baseline: ожидаемые голы оцениваются из предыдущих голов команд, со сглаживанием к среднему лиги. На validation выбирается Dixon–Coles ρ (только при минимум 100 прогнозах), затем модель сравнивается с Elo на отдельном holdout и только на матчах, где обе модели построили прогноз; покрытие показывается отдельно. Validation служит для настройки, а не для оценки качества; расчёт не использует внешний xG, не меняет live-прогнозы Elo и не является рекомендацией.
13. Раздел «Мировой рынок» раздельно показывает свежие bet365-линии через MoviOdds и названных букмекеров из The Odds API, если источник их подтвердил; он отображает вероятности без маржи, время опроса/получения, движение цены и точные сравнения с Misli/TOPAZ и Elo при однозначном совпадении. MoviOdds учитывает подтверждение 18+; The Odds API работает только в локальном personal variant с личным ключом и ограниченным суточным пакетом. Android может отложить WorkManager.
На API 34 база при последнем CI update-install содержала 39 181 объединённую строку из 184 соревнований (OpenFootball 25 904, OpenLigaDB 17 776) и 30 114 завершённых счётов. При проверке обнаружено 566 старых строк с фиктивными именами команд: они оставлены в SQLite для безопасной миграции, но скрыты от списка, моделей, купонов и оценки; новые такие строки отклоняются. После фильтрации walk-forward: 29 588 целей, 19 185 прогнозов, Brier 0.6106, Log Loss 1.0235. Это ретроспективная оценка текущих файлов, а не архивных версий источников; она не доказывает будущую точность или доход. Офлайн-перезапуск ранее сохранил расписание и статусы источников.

Последний capture 2026-11-10 21:34:53–21:35:11 UTC на API 34 вернул 0 проверяемых будущих линий у обоих операторов. Предыдущий пример Portugal—Denmark / OpenLigaDB ID 85257 с TOPAZ H/D/A 1.47/4.24/5.14 относится к захвату 21:05 UTC и давно истёк; он не доступен как текущая цена. Условия автоматического повторного использования не подтверждены; снимки остаются локальными.

## Android APK

Последняя успешная сборка: [GitHub Actions 43208538583](https://github.com/jafarovsamir89/Football-Intelligence/actions/runs/43208538583), код `ea92f9a`. Локально прошли 155 JVM-тестов, Android-test Kotlin compilation и debug/personal APK assembly. CI прошёл unit-test task, все 43 API 34 instrumentation-теста и API 26 (42 пройдены, один radio-dependent test пропущен, 0 ошибок); собрал оба варианта keyless и загрузил стабильную подписанную debug APK — артефакт `13940088159`. SHA-256 APK `87c675edc1fb6337967bb39ab3fc8b7b0ed0e0b7cf28dc83216083db176c1573`; SHA-256 сертификата `da1506fd2e896c67d3ceafc8b3ab7f33824e759e092adf938fdf11c52fa8d935`. Загруженный APK проверен и не содержит личного API-ключа. Это тестовая debug-сборка, не релиз Play Store. Личная APK с ключом собирается только локально, лежит в `app/build/outputs/apk/personal/app-personal.apk` и не должна передаваться другим лицам.

ADB в последней проверке видел только эмулятор `5558` (`memora_synthetic_capture`), где пакет Football Intelligence не установлен; физический Xiaomi не подключён. APK не устанавливался, существующие эмуляторы и их данные не менялись. Отдельный API 34 AVD для запуска key-enabled Worker не удалось создать: ему требовалось 7,37 ГБ свободного места при доступных 4,59 ГБ; временная конфигурация удалена. Поэтому прямой API POC и CI-проверки Worker не подтверждают сетевой запуск личной APK на Android. Доступность MoviOdds и операторских страниц на физическом телефоне в Азербайджане пока не проверена. Предыдущий прямой MoviOdds POC — 923 строки/904 прошедших фильтр — исторический и не является подтверждением текущих котировок.
