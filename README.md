# Football Intelligence — Android Lab

**Личная Android-лаборатория футбольных данных и виртуальных ставок.** Без платных подписок, сервера и обязательного API-ключа.

## Правила

- Нативное Android-приложение на Kotlin + Jetpack Compose с локальной SQLite. Без сервера и регистрации.
- Расписание и результаты автоматически загружаются из [OpenLigaDB](https://api.openligadb.de/index.html) и лицензированных наборов [OpenFootball football.json](https://github.com/openfootball/football.json). Ключ не нужен; локальная база остаётся доступной офлайн.
- OpenLigaDB обнаруживает доступные футбольные лиги по API, проверяет изменения и ограничивает частоту запросов. OpenFootball проверяет каталоги пяти сезонов и сохраняет фактическое время загрузки; даты без точного времени не используются как точный kickoff.
- WorkManager запускает синхронизацию при первом открытии и повторно при устаревшей базе, затем ежедневно в best-effort режиме. Android может отложить фоновые задачи.
- Misli и TOPAZ/eTopaz читаются из видимых публичных страниц стандартным Android WebView при открытом приложении. На API 34 свежий проход получил 9 линий Misli и 25 TOPAZ; 7 котировок TOPAZ точно сопоставлены с локальными матчами. Экран сформировал отдельный TOPAZ виртуальный экспресс из двух реальных свежих линий; цены и вероятности сохранены с временем снимка. Снимок старше 30 минут не используется. WebView не запускается WorkManager; условия автоматического повторного использования операторских цен не подтверждены, снимки остаются на устройстве.
- Данные, записи котировок и виртуальные ставки хранятся только на устройстве. Нет реальных ставок и подключения к букмекерским аккаунтам.
- Метрики исследовательские. Расхождение между линиями не является доказательством положительного EV.

## Реализовано

1. Автоматический сбор матчей, дат и результатов из нескольких сезонов и доступных соревнований OpenFootball и OpenLigaDB с локальным кэшем, ETag/Last-Modified, лимитом OpenLigaDB, последовательным продолжением длинного импорта и backoff для сетевых ошибок.
2. Главный экран показывает свежесть, последний успех, статус источников, список матчей и отдельную историю завершённых результатов.
3. Экспериментальный Elo 1X2 строится локально по истории той же лиги с проверкой cutoff и минимального размера выборки.
4. Раздельные виртуальные купоны Misli и TOPAZ строятся только по своему провайдеру. Конструктор проверяет свежесть и точное сопоставление каждой линии, показывает общий коэффициент только при полной линии на всех исходах и сохраняет время снимка. Если линий недостаточно, остаётся модельный подбор с маргинальными вероятностями и границами Фреше; совместное произведение вероятностей не предполагается.
5. CSV-импорт остаётся дополнительной функцией в настройках; он не нужен для обычного первого запуска.
6. Тестируются парсеры OpenFootball/OpenLigaDB, строгая дедупликация событий, статусы недоступных букмекеров и построение купона без вымышленных цен.
7. Walk-forward показывает Brier, Log Loss и one-vs-rest reliability bins для П1/X/П2: ECE, среднюю вероятность, наблюдаемую частоту и размер выборки. Это ретроспективная диагностика, не калибровка модели.

На API 34 база содержит 39 181 объединённую строку из 184 соревнований (OpenFootball 25 904, OpenLigaDB 17 776). При проверке обнаружено 566 старых строк с фиктивными именами команд: они оставлены в SQLite для безопасной миграции, но скрыты от списка, моделей, купонов и оценки; новые такие строки отклоняются. После фильтрации walk-forward: 29 588 целей, 19 185 прогнозов, Brier 0.6106, Log Loss 1.0235. Это ретроспективная оценка текущих файлов, а не архивных версий источников; она не доказывает будущую точность или доход. Офлайн-перезапуск ранее сохранил расписание и статусы источников.

Последний API 34 WebView capture от 2026-11-10 04:21 UTC получил 9 линий Misli (точных локальных связей 0) и 25 TOPAZ; выборка связала 7 котировок с точными локальными матчами по проверенным псевдонимам, ориентации команд и времени kickoff. Пример: Portugal—Denmark / OpenLigaDB ID 85257: TOPAZ H/D/A 1.45/4.31/5.29, Elo H 59.1%; экран сравнил две реальные цены 1.21/1.45 в отдельном двухисходном TOPAZ-черновике и показал границы совместной вероятности. Это снимки на время захвата, не обещание дальнейшей цены или дохода. Условия автоматического повторного использования не подтверждены; снимки остаются локальными.

## Android APK

Последняя успешная CI-сборка кода: [GitHub Actions 42757663129](https://github.com/jafarovsamir89/Football-Intelligence/actions/runs/42757663129) для `6faac0b` (83 unit-теста, APK, стабильная подпись). Сертификат SHA-256: `da1506fd2e896c67d3ceafc8b3ab7f33824e759e092adf938fdf11c52fa8d935`. Артефакт обновил API 34 с сохранением SQLite v10. APK — тестовая debug-сборка, не релиз Play Store.

На API 34 экран walk-forward отобразил 19 185 прогнозов, mean one-vs-rest ECE 2,2% (П1 3,1%, X 0,9%, П2 2,5%) и раскрываемые reliability bins. Это диагностика ретроспективной выборки, не калибровка. На API 26 Android 8 полный zero-touch sync прошёл: SQLite v10 хранит 38 609 матчей, 29 588 результатов в 183 соревнованиях; OpenFootball `OK`/25 904, OpenLigaDB `OK`/17 202, обработано 214 лиг-сезонов. Обычное продолжение после восьмиминутного сегмента отработало без exponential backoff. Ограничение: WebView этого API 26 эмулятора не вернул видимого текста для Misli/TOPAZ, поэтому там `ERROR` и нет реальных коэффициентов. На API 34 обычный WebView ранее захватил публичные линии. Физический телефон ещё не проверялся.
