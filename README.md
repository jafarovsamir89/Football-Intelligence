# Football Intelligence — Android Lab

**Личная Android-лаборатория футбольных данных и виртуальных ставок.** Без платных подписок и backend-сервера. База матчей работает без ключа; отдельный источник The Odds API использует личный бесплатный ключ только в закрытой локальной APK-сборке.

## Правила

- Нативное Android-приложение на Kotlin + Jetpack Compose с локальной SQLite и тёмной Material 3 темой. Нижняя навигация: Главная, Матчи, Купоны и Аналитика; настройки доступны через верхнюю панель. Backend и вход в приложение не нужны.
- Расписание и результаты автоматически загружаются из [OpenLigaDB](https://api.openligadb.de/index.html) и лицензированных наборов [OpenFootball football.json](https://github.com/openfootball/football.json). Ключ не нужен; локальная база остаётся доступной офлайн.
- Счёт OpenLigaDB попадает в завершённый 1X2-исход только при `matchIsFinished=true` и семантическом результате `After90Minutes`. Дополнительное время и пенальти не заменяют счёт за 90 минут; для старых payload без семантических типов остаётся fallback по ID финального результата.
- OpenLigaDB обнаруживает доступные футбольные лиги по API, проверяет изменения и ограничивает частоту запросов. OpenFootball проверяет каталоги пяти сезонов и сохраняет фактическое время загрузки; даты без точного времени не используются как точный kickoff.
- WorkManager запускает синхронизацию при первом открытии и повторно при устаревшей базе, затем ежедневно в best-effort режиме. Android может отложить фоновые задачи.
- Misli и TOPAZ/eTopaz читаются из видимых публичных страниц стандартным Android WebView при открытом приложении. Capture 21:04–21:05 UTC ранее получил 9 линий Misli и 25 TOPAZ (точные локальные связи — 0/9 и 7/25), но эти котировки истекли. Автоматическая проверка в 21:34:53 и 21:35:11 UTC не нашла на публичных страницах проверяемых будущих линий и установила `UNAVAILABLE`; новых цен не сохранено. Повторные WebView callback-и теперь коалесцируются в один capture на 30-минутное окно, и страница загружается при истечении свежести, пока приложение остаётся открытым. WAL устранил ранее воспроизведённую блокировку SQLite. WebView не запускается WorkManager; явные права повторного использования операторских котировок не подтверждены. Снимки хранятся на устройстве.
- Добавлен отдельный TipsAudit provider для производной fair-market оценки 1X2. Он не подменяет цены Misli/TOPAZ, не участвует в купонах/EV и не называется Pinnacle/Betfair/bet365. WorkManager проверяет источник при открытии, если прошлой проверки нет или прошло 15 минут, и далее best-effort каждые 30 минут. Сохраняются только события `fair_source=live`, предматчевое время чтения не старше 30 минут, валидные взаимно согласованные вероятности/цены и источник-URL; fixture link требует точные алиасы, порядок команд, дату и kickoff в пределах 20 минут. На прямом POC 2026-11-11 API вернул 98 событий, но пример Türkiye—Belgium имел `fair_read_at` на 47 минут старше capture и будет отброшен; свежая линия для сравнения на том capture не была подтверждена. На экране данные сопровождаются видимой ссылкой TipsAudit. Котировки `best_soft_odds` и сигналы value не импортируются.
- MoviOdds предоставляет котировки bet365 через независимый документированный JSON endpoint, это не прямая интеграция или одобрение bet365. Условия требуют 18+; пользователь подтвердил возраст, а разрешение остаётся специфичным для этого источника. Приложение проверяет source poll, время изменения каждой цены, полный рынок, остановку матча, дубли и точное сопоставление. Последний разбор сохраняет quality counts, 30-дневный журнал — статусы проверок; они не являются процентом надёжности. История цен сохраняет только изменения. MoviOdds сам по себе — ориентир одного букмекера; The Odds API отдельно может дать линии других именованных БК. Международные цены не входят в виртуальные купоны Misli/TOPAZ. Исторический MoviOdds POC 2026-11-12 00:39 UTC прошёл quality gate для 904 из 923 событий; работа на физическом телефоне в Азербайджане не подтверждена.
- The Odds API V4 подключён отдельным provider для EU prematch 1X2. Личный бесплатный ключ лежит только в игнорируемом `local.properties` и включается в вариант `personal`; этот APK содержит извлекаемый ключ и не должен публиковаться или отправляться в CI. Обычная CI/debug APK ключа не содержит. WorkManager запрашивает одну вращающуюся лигу раз в два часа, не более 12 попыток в любые 24 часа, сохраняет остаток квоты и приостанавливает запросы, если по последнему ответу осталось не более 20 кредитов. После ежемесячного сброса, который источник указывает на первое число, автоматический сбор возобновляется со второго UTC-дня; ошибки уважают `Retry-After`. Линии старше 15 минут не считаются свежими; каталог обновляется по очереди за несколько дней, Android может откладывать работу. По документации The Odds API стандартный ответ `h2h` автоматически включает рынок `h2h_lay` для бирж, а `includeBetLimits=true` просит доступные лимиты исходов; это не требует второго запроса. Стороны Back/Lay и ключ рынка хранятся отдельно. Lay исключён из консенсуса и проспективного сравнения Elo; спред показывается лишь для пары из одного снимка. API не передаёт комиссию Betfair, поэтому чистая биржевая доходность не рассчитывается; указанный лимит не трактуется как ликвидность. В host POC 2026-11-12 `/sports` вернул футбольный каталог без расхода квоты, а запросы EPL подтвердили формат EU 1X2 и биржевых сторон; это доказывает доступ к endpoint на момент проверки, но не live Android Worker или доступность в Азербайджане. Ответы не импортированы в базу.
- International 1X2 market comparison now exposes one equal-weight summary of Basic, Power and Shin de-vig probabilities over the same deduplicated bookmaker IDs for each exactly linked fixture. Equal weighting is descriptive, not learned; it does not establish source independence or an edge. Shin is shown as unavailable when any included book has an underround, rather than averaging a smaller subset.
- Среди рассмотренных альтернатив The Odds Gap запрещает репакетировать свою ленту в приложение; Football-Data.co.uk используется только для матчевой статистики текущего сезона с лимитом не более 2 CSV за скользящие 7 дней — его odds-колонки не читаются, а проверенный файл не содержал предстоящих цен. 1.ML требует письменного разрешения на автоматический доступ и архив. The Odds API и MoviOdds остаются двумя интегрированными международными источниками. Консенсус строится только из нескольких свежих линий разных букмекеров на одном точном матче; он не доказывает преимущество.
- Данные, записи котировок и виртуальные ставки хранятся только на устройстве. Нет реальных ставок и подключения к букмекерским аккаунтам.
- Метрики исследовательские. Расхождение между линиями не является доказательством положительного EV.

## Реализовано

1. Автоматический сбор матчей, дат и результатов из нескольких сезонов и доступных соревнований OpenFootball и OpenLigaDB с локальным кэшем, ETag/Last-Modified, лимитом OpenLigaDB, последовательным продолжением длинного импорта и backoff для сетевых ошибок.
2. Главный экран показывает, сколько ближайших матчей получили Elo-оценку и для скольких матчей есть свежая линия Misli/TOPAZ с точной локальной связью; несвязанные цены не попадают в эти счётчики. В короткой подборке сначала идут игры с уже готовым прогнозом, чтобы расчёт не терялся за более ранними матчами без достаточной истории. Список также сохраняет предстоящие игры, для которых источник сообщил только дату: им не придумывается время или прогноз Elo. Нажатие на матч открывает вероятности 1X2, актуальные цены и сравнение. Разбор объясняет конкретную оценку: рейтинг Elo хозяев и гостей, домашний фактор, число использованных результатов до начала игры и сглаженный ориентир ничьих; самая высокая вероятность названа наиболее вероятным исходом модели, а не советом ставить. Снимок прогноза автоматически сохраняется для последующей проверки по счёту. Если истории или точного времени не хватает, разбор показывает причину; если купон пока недоступен, экран сообщает количество готовых оценок и открывает список матчей. На пустой новой установке Главная объясняет синхронизацию; при сбое теперь показывает источник ошибки вместо старого успешного времени, а раскрытые детали перечисляют статус, число записей и время проверки каждого источника. Сохранённые матчи доступны офлайн. Даты и время отображаются по Баку.
3. Аналитика включает мировой рынок, бэктест, проспективную статистику моделей и историю результатов. Длинные сведения об источниках и экспериментальных сравнениях раскрываются по запросу; CSV импорт остаётся в настройках.
4. Live-прогнозы остаются на Elo. Отдельный исследовательский бэктест сравнивает Elo с goal-based Poisson/Dixon–Coles и venue-split Home/Away baseline по строгому времени доступности и хронологическим validation/holdout. На validation подбираются вес Elo/Poisson и общая multiclass temperature scaling (фиксированная сетка 9×9) по Log Loss. Кандидату нужны минимум 500 общих прогнозов в validation и holdout; на каждом срезе он должен превзойти Elo и Poisson одновременно по Brier и Log Loss. Для кандидата и обоих базовых методов показывается one-vs-rest ECE на validation и holdout. Смесь остаётся исследовательской и не меняет live-прогнозы/купоны; два исторических среза не подтверждают будущую точность. Live Elo остаётся некалиброванной. Для парных holdout-разниц Brier и Log Loss выводятся детерминированные bootstrap 95% интервалы только при 30+ общих матчах; зависимость повторных команд может занижать их ширину.
   Отдельно доступны walk-forward Brier и Log Loss Elo по соревнованию и сохранённой метке сезона. Метка сезона берётся из источника и не восстанавливается по дате; строки без неё сгруппированы отдельно, а выборки меньше 30 помечаются как малые.
5. Раздельные виртуальные купоны Misli и TOPAZ строятся только по своему провайдеру. Кроме подбора по вероятности модели, доступен отдельный исследовательский подбор по положительному расхождению с полной свежей линией того же букмекера после удаления маржи. Он требует точной связи с локальным матчем; сохраняет рыночную вероятность, разницу и время цены; для него EV/ROI не показываются. В остальных ценовых купонах общий коэффициент есть только при полной линии на всех исходах. Для совместной вероятности используется диапазон Фреше без допущения независимости. Купон сразу считается проигранным после первой неверной завершённой ноги; процент покрытия ценами показывается отдельно.
6. CSV-импорт остаётся дополнительной функцией в настройках; он не нужен для обычного первого запуска.
7. SQLite v19 хранит TipsAudit fair-market snapshots, линии MoviOdds и The Odds API, а также воспроизводимые значения сравнения модели с местной линией в отдельных регистрах/полях. В международном регистре разделены текущие котировки и история, provider/book identity, source poll и capture timestamps, 30-дневные статусы и quality counts. Для The Odds API Back и Lay сохраняются раздельно вместе с `h2h`/`h2h_lay` и исходными лимитами. Миграции v17→v18 и v18→v19 сохраняют котировки и локальные матчи; v19 добавляет отдельные таблицы статистики матчей и лимита запросов. Связь с локальным матчем требует точного kickoff либо единственного совпадения команд и UTC-даты; точность связи сохраняется и показывается. Неоднозначные совпадения отклоняются. Misli/TOPAZ и международные источники остаются изолированными.
8. Football-Data.co.uk автоматически добавляет удары, удары в створ, угловые, фолы и карточки к точным завершённым матчам. Провайдер хранит происхождение, время загрузки и консервативное время доступности; один запрос загружает одну лигу текущего сезона. Локальный gate допускает не более двух CSV за скользящие семь дней. Коэффициентные колонки CSV не используются. Эти статистики видны в истории результатов и пока не меняют прогнозы Elo.
9. Walk-forward показывает Brier, Log Loss и one-vs-rest reliability bins для П1/X/П2: ECE, среднюю вероятность, наблюдаемую частоту и размер выборки. Это ретроспективная диагностика, не калибровка модели.
10. Будущие прогнозы модели фиксируются в SQLite неизменяемыми снимками на матч, версию Elo и UTC-день. Отчёт читает весь локальный журнал и для метрик выбирает последний прогноз до kickoff по одному разу на матч/версию модели; проверяет счёт, исход, источник и время доступности результата. Виден список последних 100 записей. До накопления завершённых, проверяемых матчей метрики остаются пустыми.
11. Мировой рынок показывает парную проверку Elo и последней сохранённой свежей международной линии до kickoff по тому же матчу. Букмекеры считаются отдельно; цена оценивается после доступности результата, а отчёт явно показывает объём пар и pending исходы. При минимум 30 завершённых матчах выводятся детерминированные 95% paired-bootstrap интервалы разницы Elo−рынок для Brier, Log Loss и top-1; ниже порога интервалы скрыты. При обновлении локального снимка сводная оценка временно заменяется сообщением о пересчёте, тогда как котировки и история остаются видны. Это локальный описательный отчёт, не CLV или ROI.
12. Экран анализа сравнивает 27 заранее заданных комбинаций K-фактора, домашнего преимущества и prior ничьих. Параметры выбираются только на следующем хронологическом validation-отрезке по Log Loss; отдельный последний holdout сравнивает выбранные настройки с текущими. При менее чем 100 рассчитанных validation-прогнозах выбор не делается. Это исследовательский расчёт на текущих файлах, не меняющий замороженные или рабочие прогнозы.
13. Журнал экспрессов показывает покрытие полностью сохранёнными ценами. ROI, profit factor и drawdown рассчитываются только если цена есть у каждого завершённого купона в соответствующей группе.
14. В ретроспективном анализе доступен исследовательский Poisson baseline: ожидаемые голы оцениваются из предыдущих голов команд, со сглаживанием к среднему лиги. На validation выбирается Dixon–Coles ρ (только при минимум 100 прогнозах), затем модель сравнивается с Elo на отдельном holdout и только на матчах, где обе модели построили прогноз; покрытие показывается отдельно. Validation служит для настройки, а не для оценки качества; расчёт не использует внешний xG, не меняет live-прогнозы Elo и не является рекомендацией.
15. Раздел «Мировой рынок» раздельно показывает свежие bet365-линии через MoviOdds и названных букмекеров из The Odds API, если источник их подтвердил; он отображает вероятности без маржи, время опроса/получения, движение цены и точные сравнения с Misli/TOPAZ и Elo при однозначном совпадении. MoviOdds учитывает подтверждение 18+; The Odds API работает только в локальном personal variant с личным ключом и ограниченным суточным пакетом. Android может отложить WorkManager.

При проверке обнаружено 566 старых строк с фиктивными именами команд: они оставлены в SQLite для безопасной миграции, но скрыты от списка, моделей, купонов и оценки; новые такие строки отклоняются. После фильтрации walk-forward: 29 588 целей, 19 185 прогнозов, Brier 0.6106, Log Loss 1.0235. Это ретроспективная оценка текущих файлов, а не архивных версий источников; она не доказывает будущую точность или доход. Офлайн-перезапуск ранее сохранил расписание и статусы источников.

Последний capture 2026-11-10 21:34:53–21:35:11 UTC на API 34 вернул 0 проверяемых будущих линий у обоих операторов. Более ранние снимки и купоны уже истекли и не представлены как текущие цены. Условия автоматического повторного использования не подтверждены; снимки остаются локальными.

## Как пользоваться

1. Откройте **Матчи** и выберите игру, чтобы увидеть расчёт Elo, доступную историю команд и найденные свежие линии. В сравнении с линией «+» означает, что Elo оценивает исход выше снятой от маржи рыночной вероятности, «−» — ниже; наибольшая положительная разница выделена. Это только гипотеза для проверки: модель не откалибрована, а разница не является советом или доказанным преимуществом.
2. В **Купонах** просматривайте виртуальные подборы отдельно для Misli и TOPAZ. Без свежей полной линии приложение показывает исходы и вероятности модели без коэффициента. В подробностях совместный шанс выражен границами Фреше: зависимость матчей неизвестна, а диапазон не подтверждает реальную вероятность экспресса.
3. В **Аналитике** доступны международные ориентиры, хронологическая проверка моделей и история результатов. Ретроспективные метрики описывают текущие данные; они не доказывают точность будущих прогнозов.
4. На первом запуске база загружается автоматически, когда есть сеть. При пустой базе главный экран показывает статус и ссылку на детали источников; Android может отложить фоновую задачу. После загрузки матчи и история остаются доступны офлайн.
