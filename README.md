# Football Intelligence — Android Lab

**Личная Android-лаборатория футбольных данных и виртуальных ставок.** Без платных подписок, сервера и обязательного API-ключа.

## Правила

- Нативное Android-приложение на Kotlin + Jetpack Compose с локальной SQLite. Без сервера и регистрации.
- Расписание и результаты — [OpenLigaDB](https://api.openligadb.de/index.html), без регистрации и ключа, только поддерживаемые лиги. API ограничен 60 запросами в минуту/IP; приложение обновляет данные по действию пользователя.
- Коэффициенты автоматически не обещаются: пользователь вводит три исхода 1X2 одного букмекера. Доступность цены не проверяется.
- Прогнозы игроков добавляются вручную с указанием источника и остаются неподтверждёнными.
- Данные, записи котировок и виртуальные ставки хранятся только на устройстве. Нет реальных ставок и подключения к букмекерским аккаунтам.
- Метрики исследовательские. Расхождение между линиями не является доказательством положительного EV.

## Реализовано

1. Загрузка выбранных сезонов Бундеслиги и второй Бундеслиги, локальное хранение матчей и показ сохранённых данных офлайн.
2. Ручной ввод и история линий рынка 1X2.
3. Удаление маржи: Basic, Power и Shin; простое среднее свежих пользовательских записей отдельно помечено как не проверенная рыночная вероятность.
4. Ручной ввод прогнозов игроков с явной пометкой, что они не подтверждены реальными ставками.
5. Виртуальные одиночные ставки с фиксацией до матча и ROI по рассчитанным ставкам.
6. Чистые Kotlin-примитивы Poisson и Dixon–Coles, Brier score, log loss и EV с unit-тестами.
7. Экспериментальный Elo-baseline для выбранного матча: использует сохранённую историю той же лиги до начала, скрывает вероятности при малой выборке и явно помечается как некалиброванный.
8. Ручной CSV-импорт завершённых результатов через системный файловый выбор Android. Сохраняются метка формата/источника (не проверяется), имя файла, время импорта и дата матча; коэффициенты игнорируются, а строки с одной только датой откладываются на два дня для защиты от временной утечки.
9. Экран walk-forward использует импортированные результаты отдельно от текущих матчей, делит данные по календарным датам, применяет `available_at` с двухдневной задержкой и сообщает средние Brier/Log Loss и число пропусков из-за малого сэмпла. Результат — ретроспективная оценка без market baseline, source vintages и калибровки.

Импортированные результаты пока не подключены к текущим матчам. Импорт коэффициентов/JSON, экспорт данных, экспрессы и сравнение с историческим market baseline ещё не реализованы.

## Android APK

В GitHub Actions открой workflow **Build Android Debug APK** и запусти сборку. После успешного выполнения скачай artifact football-intelligence-debug-apk и установи app-debug.apk на Android. APK — тестовая debug-сборка, а не релиз для Play Store.

GitHub Actions run [42711478723](https://github.com/jafarovsamir89/Football-Intelligence/actions/runs/42711478723) проверил коммит `a4dc94f`, прошёл 26 тестов и загрузил artifact football-intelligence-debug-apk. Текущая walk-forward версия проходит локально 32 теста и сборку; для неё требуется отдельный CI run. Для локальной проверки используй JDK 17 и команды из TESTING.md.
