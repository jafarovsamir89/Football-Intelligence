# Football Intelligence — Android Lab

**Личная Android-лаборатория футбольных данных и виртуальных ставок.** Без платных подписок, сервера и обязательного API-ключа.

## Правила

- Нативное Android-приложение на Kotlin + Jetpack Compose с локальной SQLite. Без сервера и регистрации.
- Расписание и результаты автоматически загружаются из [OpenLigaDB](https://api.openligadb.de/index.html) и лицензированных наборов [OpenFootball football.json](https://github.com/openfootball/football.json). Ключ не нужен; локальная база остаётся доступной офлайн.
- OpenLigaDB обнаруживает доступные футбольные лиги по API, проверяет изменения и ограничивает частоту запросов. OpenFootball проверяет каталоги пяти сезонов и сохраняет фактическое время загрузки; даты без точного времени не используются как точный kickoff.
- WorkManager запускает синхронизацию при первом открытии и повторно при устаревшей базе, затем ежедневно в best-effort режиме. Android может отложить фоновые задачи.
- Misli и TOPAZ/eTopaz автоматически читаются из видимых публичных страниц обычным Android WebView при открытии приложения. На API 34 проверено получение 8 линий Misli и 25 линий TOPAZ без входа в аккаунт или скрытых endpoints. Снимки 1X2 сохраняются локально и показываются свежими до 30 минут; WebView работает при открытом приложении, WorkManager его не запускает. Разрешение операторов на автоматическое повторное использование коэффициентов не подтверждено; снимки не передаются наружу.
- Данные, записи котировок и виртуальные ставки хранятся только на устройстве. Нет реальных ставок и подключения к букмекерским аккаунтам.
- Метрики исследовательские. Расхождение между линиями не является доказательством положительного EV.

## Реализовано

1. Автоматический сбор матчей, дат и результатов из нескольких сезонов и доступных соревнований OpenFootball и OpenLigaDB с локальным кэшем, ETag/Last-Modified, лимитом OpenLigaDB, backoff и сохранением provenance.
2. Главный экран показывает свежесть, последний успех, статус источников, список матчей и отдельную историю завершённых результатов.
3. Экспериментальный Elo 1X2 строится локально по истории той же лиги с проверкой cutoff и минимального размера выборки.
4. Автоматические модельные черновики раздельно отображаются для Misli и TOPAZ, сохраняют исход и вероятность для последующей проверки результата. Цены оператора показываются только при точном свежем сопоставлении матча; без цены нет общего коэффициента или выплаты.
5. CSV-импорт остаётся дополнительной функцией в настройках; он не нужен для обычного первого запуска.
6. Тестируются парсеры OpenFootball/OpenLigaDB, строгая дедупликация событий, статусы недоступных букмекеров и построение купона без вымышленных цен.

Чистая установка API 34 автоматически собрала 39 330 матчей из 188 соревнований и пяти сезонов; 30 180 строк содержали завершённый счёт. Были сохранены 8 линий Misli и 25 TOPAZ, включая публичные матчи, сверенные с расписаниями УЕФА. Эти котировки пока не сопоставились с точными локальными прогнозами, поэтому приложение не приписывает им модельные вероятности. Встроенный walk-forward по автоматической истории обработал 29 970 целей: 19 078 прогнозов, средний Brier 0.6105 и Log Loss 1.0234; это ретроспективная оценка текущих файлов без архива исторических версий источников, не доказательство будущей точности или дохода. Работу без сети проверили: сохранённая база открывается офлайн. WorkManager может быть отложен Android.

## Android APK

Последняя успешная сборка: [GitHub Actions 42731002068](https://github.com/jafarovsamir89/Football-Intelligence/actions/runs/42731002068), artifact `football-intelligence-debug-apk`. APK — тестовая debug-сборка, а не релиз для Play Store. CI APK подписываются стабильным приватным тестовым ключом, чтобы их можно было обновлять без удаления локальной базы; локальный APK с компьютера имеет другой debug-сертификат. Сборка с исправлением повторного запуска синхронизации ещё проверяется.

Последняя локальная проверка: 62 JUnit-теста и `assembleDebug` прошли. Artifact Actions установлен на API 34 после чистой установки и автоматически начал заполнять локальную базу.
